This capstone project is part of the "Complete Full-Stack Web Development Bootcamp" by 
Dr. Angela Yu at Udemy.

The goal of this project is to create a Blog web application using Node.js, Express.js, and EJS. 
The application will allow users to create, view, update and delete blog posts. Posts will persist 
with the use of a data file. Styling will be an important aspect of this project to ensure a good 
user experience.

To run this website, you will need to have vscode, node, and npm installed.  Then,
- Use "npm install", at the root folder, to get the dependencies installed.
- Run the website with "node index.js".
- Open Chrome and goto address "http://localhost:3000/", to access the website.
